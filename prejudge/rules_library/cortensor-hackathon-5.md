# Cortensor Hackathon #5 (OpenMinion 0.1 builder round)

Source: https://dorahacks.io/hackathon/2418/detail — condensed by PreJudge, check the page for changes.
Deadline: 2026-12-18 (Pacific Time). Virtual.

## Goal

Build a small, working agent or agent-powered app with the OpenMinion 0.1 Python SDK.
It must use the SDK as a meaningful part of its runtime, complete one useful repeatable workflow,
show a real model-backed run in a short demo, and report which OpenMinion building blocks were
tested (execution, models, tools, permissions, sessions, memory, skills, tasks, delegation,
diagnostics), including bugs and rough edges. Cortensor Portal / Gemma4 use is optional bonus.

## Evaluation

- Working functionality and useful outcome: 25%
- Meaningful OpenMinion SDK usage: 20%
- Reproducibility and demo quality: 20%
- Building-block findings and improvement feedback: 25%
- Relevance to Cortensor builder workflows: 10%

## Submission checklist

Your PR should include:
- A public source repository and README with setup and run instructions
- A short explanation of the OpenMinion SDK workflow
- One working example and a 1–5 minute demo video
- A Building Blocks Tested note: what was used, what worked, what did not
- A What We Learned note with actionable product feedback

Bug reports need reproduction steps, expected vs actual behavior and safe evidence.
Bonus: Portal or Gemma4 testing, fix PRs for acknowledged bugs, reusable tools, tests, docs.
Keep secrets and private data out of public submissions.
